## 2. 必须先选定模型的职责

| 职责 | 能改善什么 | 边界 |
|---|---|---|
| 固定候选的 keep/drop 评分器 | 候选排序、阈值取舍及 annotation FP | 不生成边界，不恢复现有 21 个无可匹配候选 FN |
| 合法候选组的集合评分/选择器 | 一对一目标与多个正候选竞争 | 需要推理可得分组；9 个跨 record 案例不能默认已覆盖 |
| 新事件/边界生成器（本阶段范围外） | 可能改变 coverage | 只记录依赖；新增边界须交路线2，直接时序生成路线不在本次路线3设计范围 |

本阶段只设计前两类中的固定候选评分或合法集合模型，证明一个信息或目标增量并保留低容量。不得自动转入新事件/边界生成设计；需要该职责时记录路线2依赖与另行决定事项，不同时更改 candidate、representation、loss 和 decoder。

## 3. 支持、反证与未证部分

现有固定 26D 相比 A1 增加 pooled F1 0.038396，但只净增 1 个 TP，仍有 79 长 FP，五折均未达 0.66。它说明这一固定上下文摘要不足以满足当前投入门槛；不证明所有事件模型无效，也不证明继续扩大上下文必然有效。

可值得检验的两种增量：

1. **顺序信息**：同样的均值、分位数、正窗口比例和 longest run 可能对应不同时间排列。有限时序形态可能区分持续低密度支持与结构化事件。当前未证明这些差异对标注可辨；先核验现有16/26D是否已经表达所提信息，不能以“维度更多”代替证据。
2. **集合目标**：候选 any-GT positive 允许同 GT 多个正候选，而 one-to-one 输出只计一个 TP。11 个分离竞争案例支持研究集合目标。GT 竞争关系是训练/诊断监督，不是推理分组；无法找到无 GT 分组时该机制不成立。

反证与限制：TP 也有长时段和不连续 support；58 个零注释交叠候选不能通过纯子区间编辑变成 TP；17 个有非负支持 FN 仍无可匹配候选；低覆盖和全负输入不能靠换候选评分器自动补回。长 GT 也可能需要跨多个观察 component 的标签解释，不能预设序列应更短。

官方非惯用手 PPG 与针对性算法要求仍有设计证据缺口。本轮不批准读取新 PPG/raw；不得借队友低频 HRV 失败结论宣布所有 PPG 无效。

## 4. 下一对话先完成的具体工作

允许完成证据/设计文档，不训练或调用模型，也不执行新特征性能实验。

### 4.1 信息增量清单

对每个拟议输入列出：逻辑定义、已有16/26D中相关列、所需原始来源是否已经注册、时间/record/session/component边界、未来依赖、推理是否可得、空值含义、是否含标签、预计容量。可读取已批准的几何/质量和保存分数核对定义；不能自动加载所有缓存 feature 数组、未注册 PPG/HRV sidecar 或 raw 补建。

只选择一个主要增量，记录为什么已有摘要不能等价表示，以及哪种保存证据可能反驳这一点。若只是冗余重命名，建议暂缓模型投入，完成这一负面设计结论即可。

### 4.2 监督与角色隔离图

定义 label-free 推理特征视图、训练标签 join、candidate composite identity=(role_id,candidate_id)，保留 canonical GT 身份。若用 set/ranking supervision，明确训练折 GT 如何构造关系，held-out label 在何处只作评价；推理组由输入字段生成，不由 GT 指定。

每个 fold/layer 的 fit、threshold reference、selection、held-out participants 要可列举且互相满足隔离。任何时间先验、标准化、关系分组学习、上游 scorer/候选选择和阈值均在相应训练层内。不能以“已有 outer OOF”替代更深层隔离，也不能继承队友未重建的内层上游特征。

### 4.3 输出接口和失败处理

只选择 keep/drop 或 set selector，定义输入身份、score 到既有 interval 的投影、缺失观察表示、输出数/关系规模控制、ties与空输入。保留 GT-free 推理；不把未知缺口填成非进食，不跨 record 拼接长事件。每个异常有 INVALID/资源不足/数据不足等独立类别，不靠换 seed、缩 fold 或删参与者继续。

## 5. 方案比较与最小可证伪建议

均为讨论建议，当前不执行，实际配置/角色计数/预算在具体方案定稿后才可确定。

| 方案 | 机制与支持 | 反证、缺失证据 | 最小可证伪建议 | 成本与停止条件 |
|---|---|---|---|---|
| R3-A：固定候选的有限顺序摘要 + 低容量 scorer | 预先限定时间片/顺序形态，可用线性模型或受限 HGB；只改变一种明确表示。长 FP 与 TP 可能在顺序而非均值上不同 | 现有摘要是否已充分、保存分数的分辨率、丢失窗口如何表达、合法上下文范围；没有已确认分类可辨性 | 固定候选、标签、decoder与匹配；比较原表示和单一新增顺序信息，模型容量/选择机制配平。检验净 TP/FP/FN、long FP及边界，最终一次开发评价 | 特征成本约随 N×p 增长，训练成本需实测准备，不继承A2 fit许可。冗余信息、需未经授权数据、只 outer 个案受益或达不到预注册投入门槛，停止该固定变体 |
| R3-B：合法组内 ranking/集合选择 | 用训练折关系优化同组候选竞争，不仅独立 any-GT 二分类；11 非交叠案例提供目标差异证据 | 无 GT 的分组、跨 record输入未知、最佳候选是否可辨、one-to-one本地约定的影响 | 固定候选、个体表示、相同推理组和相同选择规则，只改变学习目标；与同容量独立分类比较，报告保留 TP、删除 FP和新漏报。不得同时增加时序表示 | 关系数约 sum(g²)，须限定组及 pair规模；不能默认全participant两两。分组依赖GT、跨输入前提不成立或未通过预注册同分母F1/逐折门槛及约束，停止 |
| R3-C：有限事件序列/边界模型（范围外，仅作取舍参考） | 能保留更完整时间形态并提出新边界，可能影响21 FN | 样本少、开发已使用41人、低覆盖/全负与标签跨度、官方上下文/资源未知；现证据不足以支持更高容量 | 本次不形成该生成模型的设计或验证；先交路线2确认边界需求，未来是否投入须另作明确路线决定 | 较高内存、训练与隔离成本，当前推荐暂缓。接口未审、成本无法约束或无信息增量证据，不进入设计或训练 |

没有任何方案预承诺 F1≥0.66；相同候选的评分/集合模型只能优化已覆盖 GT 的取舍。若目标包含恢复 21 个 FN，必须显式引入新的合法候选或边界机制，归入单独设计与预算。

损失少量 TP 不能单独判失败，删除 FP 的数量不能代替同分母 F1、既有逐折门槛与预注册约束。matched MAE 比较同时报告匹配 GT 集合变化，不能把删除难匹配事件造成的 MAE 降低归因于边界更准。

## 6. 未来验证说明应具备的内容

- 一个冻结假设与一个科学变化；阈值、模型家族、容量、context width、seed及来源明确，不安排 family/feature sweep。
- 精确输入白名单、角色和标签隔离、模型调用图及实际次数；单一模型方案可据图计算 logical fits，不能复制 A2 的25次作为自动授权。
- 资源初值与计量方案、累计 attempts/wall/RSS/disk/threads、失败和中断计数、不可清理历史和不可自动重试条款；成本无测量时诚实保留未确定。
- 比较基线协议对齐；若换候选或 matcher，标明旧分数不可直接作唯一区别归因。
- numeric/stage/local gate分别报告；若申请不同 gate，先给理由并取得明确新决定，不能自动绕过G1或把full training解锁。
- 成功只算发展证据，失败只关闭固定变体；明确不会从其结果推断模型家族全部有效/无效。

若机制证据不足，应交付“暂缓模型投入”及能改变该决定的证据清单。不要为了满足模型路线名称而生成一次无信息增量的训练。
